# Security policy

AI Window Manager is a self-hosted, single-operator application for trusted
private networks. It is not intended to be exposed directly to the public
Internet. Review [the security and deployment guidance](docs/security.md)
before operating it.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or discussions.
Use GitHub's private vulnerability reporting feature for this repository when
it is enabled. If private reporting is unavailable, contact the maintainer
through the GitHub profile at <https://github.com/Nerver-zip> and request a
private reporting channel; do not include exploit details in a public message.

Include the affected commit or release, impact, and a minimal reproduction when
safe to do so. Do not include real provider credentials, tokens, cookies,
account data, or unredacted database/provider state.

## Supported versions

Until the first tagged release, security fixes are made against the latest
`main` source. After tagged releases exist, the latest release is the supported
version unless a security advisory states otherwise. No response-time SLA is
promised for this personal self-hosted project.
